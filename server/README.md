# API учебного планировщика

Из папки `server` установите зависимости (`yarn install`) и запустите `yarn start:dev`.
PostgreSQL должен быть запущен. Настройки читаются из корневого `../.env`.
HTTP-порт задаётся `SERVER_PORT`, по умолчанию — 4321.

## Документация

- Swagger UI: http://localhost:4321/docs
- OpenAPI JSON: http://localhost:4321/docs-json

В Swagger раскройте операцию, нажмите **Try it out**, заполните параметры и нажмите **Execute**.
Запросы создания, изменения и удаления работают с настоящей базой.

## Пагинация задач

`GET /tasks?page=1&limit=20&search=название&subjectId=1`

- `page`: номер страницы от 1 до 1000000, по умолчанию 1.
- `limit`: размер страницы от 1 до 100, по умолчанию 20.
- `search`: необязательный поиск подстроки в названии без учёта регистра.
- `subjectId`: необязательный положительный целочисленный идентификатор предмета.

Ответ списка теперь содержит объект вместо прежнего массива:

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "limit": 20,
  "totalPages": 0
}
```

`total` — количество задач после применения фильтров, до ограничения страницы.
Для страницы за пределами списка `items` пуст, а `total` сохраняется.
Сортировка стабильная, по `id` по возрастанию.
Количество и элементы читаются отдельными запросами: при одновременных изменениях
базы между ними возможна небольшая разница.

## CORS

В корневом `.env` задайте разрешённые адреса фронтенда через запятую:

```dotenv
CORS_ORIGINS=http://localhost:5173,http://localhost:3000
```

Указывайте origin (протокол, хост и порт) без пути и завершающего слеша.
`127.0.0.1` и `localhost` — разные origin. После изменения перезапустите сервер.
По умолчанию разрешены указанные выше два адреса. Cookie credentials не включены.
