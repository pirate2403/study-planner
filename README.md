# Учебный планировщик

Приложение для учёта учебных заданий. Помогает собрать задания по разным предметам в одном месте, записать требования и сроки сдачи, быстро найти нужную работу.

У каждой задачи есть название, описание, предмет и срок выполнения. Задачи можно создавать, редактировать и удалять. В списке предусмотрены поиск по названию, фильтр по предмету и переключение страниц. Предметы ведутся отдельно: их можно добавлять и переименовывать. Удалить предмет с заданиями нельзя.

## Технологии

- Клиент: React, TypeScript, Vite.
- Сервер: NestJS, PostgreSQL, node-postgres.
- Инфраструктура: Docker Compose, Nginx.
- Документация API: Swagger. Форматирование: Prettier.

## Запуск

Нужен запущенный Docker. Из корня проекта:

```bash
cp .env.example .env
```

Укажите пароль базы в `.env`, затем запустите приложение:

```bash
docker compose up -d --build --wait
```

- Приложение: http://localhost:5173
- HTML-макеты: http://localhost:5173/mockup.html
- Swagger: http://localhost:4321/docs

Настройки клиента, сервера и базы находятся в корневом `.env`. Данные PostgreSQL сохраняются в Docker-томе после остановки контейнеров.

## Скрипты

Из корня проекта:

| Команда               | Действие                                |
| --------------------- | --------------------------------------- |
| `npm run docker:up`   | Собрать и запустить приложение в Docker |
| `npm run docker:down` | Остановить контейнеры                   |
| `npm run docker:logs` | Показать логи сервера и базы            |
| `npm run db:up`       | Запустить только PostgreSQL             |
| `npm run db:down`     | Остановить PostgreSQL                   |
| `npm run dev:server`  | Запустить сервер в режиме разработки    |
| `npm run dev:client`  | Запустить клиент в режиме разработки    |

Для локальной разработки нужна Node.js 24. Зависимости устанавливаются отдельно: `yarn install` в `server`, `npm install` в `client`. Контейнеры клиента и сервера перед локальным запуском нужно остановить, чтобы освободить порты.

В папке `client`: `npm run build` — сборка, `npm run lint` — проверка кода, `npm run format` — форматирование.

В папке `server`: `yarn build` — сборка, `yarn lint` — проверка кода, `yarn format` — форматирование.
